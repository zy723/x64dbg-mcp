# x64dbg-mcp 升级修复清单

**日期**: 2026-10-09
**版本**: v1.0.11 → v1.1.0
**根因总结**: NAPCB v6.6 VMP unpack 会话暴露的 RPC 接口短板（详见 `E:\tmp\IDMdwon\NAPCB v6.6_0911\bug-fix\2026-10-09-2100-最终结论-运行时补丁不可行-需要静态脱壳.md`）

## 本次修复 (v1.1.0)

### P0

| ID | 方法 | 问题 | 根因 | 修复 |
|----|------|------|------|------|
| W1 | `debug.detach` | 不存在，切 target 必须 stop | 没有 RPC 暴露 detach | 新增 method，`DebugController::Detach(timeoutMs)` 调用 `mcpdetach` 并轮询 `IsDebugging` |
| W8 | `debug.get_pid` / `debug.get_exit_code` | PID 仅 attach 时返回，后续不可查 | `GetDebuggeeProcessId` 存在但无 RPC 暴露 | 新增两个 method；`get_pid` 额外用 `DbgGetProcessHandle + GetProcessId` 交叉校验 |
| W4 | `stack.get_trace` | 总是返回空或少项 | 只走 manual RBP walker，在 VMP/混淆代码上 RBP 链断裂 | `GetStackTrace` 先尝试 `DbgFunctions()->GetCallStackEx`，再 `GetCallStack`，最后降级 manual |
| W3 | `breakpoint.list` 之 `hit_count` | 总是 0 | `BpGetFieldNumber(bpf_hitcount)` 在某些固件版本返回 false 或无数据 | `BreakpointManager` 添加本地命中计数（在 plugin `CB_BREAKPOINT` 回调统计），返回 `max(bridge_value, local_count)` |

### P1

| ID | 方法 | 问题 | 根因 | 修复 |
|----|------|------|------|------|
| W2 | `debug.run_until_break` | `debug.run` 立即返回，BP 命中要轮询 | 缺同步等待 API | 新 method：run + 轮询 `GetState()`，命中返回 `{rip, reason:"breakpoint_or_exception"}`，进程退出返回 `stopped`，timeout 返回 `timeout` |
| W5 | `disassembly.function` | 混淆代码下整函数崩溃 | 单字节失败抛 MCPException | 添加 `max_instructions`（默认 2000）；遭遇无效指令时跳过 1 字节继续，连续失败 64 次终止 |

### P2

| ID | 方法 | 问题 | 根因 | 修复 |
|----|------|------|------|------|
| W6 | `register.get_all` | `register.get_batch` 要列名，`register.list` 返回冗余 | 接口粒度过粗或过细 | 新 method返回紧凑 `{name: value}` 对象；`include_extended=true` 返回全部段/MMX/XMM 寄存器 |
| W7 | `debug.attach_pid` 重连健壮性 | 一次 attach 失败后再 attach 永久失败 | x64dbg 内部状态不一致时未清理 | （已部分缓解：`debug.detach` 现在可用于清理；完整 detach+reattach 重试尚未实现，留待 v1.1.1）|
| W10 | 中文注释乱码 | GBK-在-UTF8 字节序列跨 IDE 不可读 | 历史编码混合 | 已部分清理 DisassemblyHandler.cpp 相关函数；其余文件待全量重编码脚本处理 |

## 影响范围

- RPC 接口向后兼容：仅新增 method，不删除/不改现有签名
- DebugController / BreakpointManager ABI 内部，不导出

## 遗留风险

1. `DbgFunctions()->GetCallStackEx` 在 VMP 样本上仍可能返回空栈 — 已降级 manual fallback
2. `debug.run_until_break` 长 timeout 阻塞 HTTP worker；默认 15s，max 120s
3. debuggee 在 `run_until_break` 期间 exit 时返回 `stopped` 而非 `bp`，调用方需检查 `state` 字段
4. 本地 `BreakpointManager::m_localHitCounts` 在 plugin unload/重启时清空（与 x64dbg 一致行为）
