## 遗留风险

1. **乱码注释编码转换官方未解决**: PluginEntry.cpp 历史 GBK-in-UTF8 字节, 实测 PowerShell `[Text.Encoding]::GetEncoding('GB18030')` 转换有 side effect (中文转义错误)，已回滚 git checkout。需要专门 script (chardet+iconv) 一次性重建, 但**当前不阻塞功能**——乱码仅在源码注释，不影响二进制行为。
2. x64dbg 装载的 .dp64 仍是旧版（b917471），用户需要重启 x64dbg 才能让 v1.1.0+审计修复生效。
3. attach_pid retry 路径用了 `ExecuteCommandDirect("stop")` 同步执行，可能与 GUI 消息队列有竞争；如果用户实测仍然失败，需进一步在 retry 前等 DbgIsRunning()=false 才发 mcpattach。
